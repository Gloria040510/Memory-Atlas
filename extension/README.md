# Memory Atlas 浏览器扩展

Chrome / Edge Manifest V3，无远程脚本、无第三方依赖。

1. 下载并解压 ZIP。
2. Chrome：chrome://extensions；Edge：edge://extensions。开启开发者模式，加载已解压文件夹。
3. 刷新已有 ChatGPT 和 Memory Atlas 标签页。
4. 在网站「连接实时同步」中开启接收。
5. 打开已保存的 ChatGPT 对话，在扩展弹窗点击「开启当前对话」。

采集仅针对逐个开启的对话，在回答停止约 2 秒后收集已加载文字；可能因页面持续更新延迟至下次 7 秒检查。不会读取隐藏历史、Cookie、密码、附件或图片。受网页 DOM 结构影响，不保证全文完整，历史数据请使用官方导出。

图谱关闭时，最多暂存 20 段、共 4 MB；单段最多 2 MB。再次打开图谱后自动补传。暂停某段对话会同时移除它的待传缓存。采集失败会在弹窗展示，已同步内容不会因暂停而删除，可在网站管理对话。

旧对话使用首次采集日期作为近似日期，可在网站原文页修正。消息通过同一浏览器扩展通信与同源页面消息传递进入 IndexedDB，不发送到外部服务器。
